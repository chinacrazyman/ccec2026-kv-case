## 二、实验总体目标

本实验围绕高并发 KV 系统中的性能、安全、并发与容量问题，完成四个递进式实验：

1. 通过二维数组行列遍历实验，理解 CPU Cache 与空间局部性对程序性能的影响。
2. 通过 HashMap 极端碰撞实验，理解哈希表复杂度退化与 Hash DoS 风险。
3. 通过多线程并发写入实验，理解 HashMap 线程不安全问题及并发容器的同步策略。
4. 通过 Bloom Filter 实验，理解海量数据判重中的空间代价、误判率与工程权衡。
